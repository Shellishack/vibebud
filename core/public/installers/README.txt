Drop platform installers here. The /installers directory is served as static files
by Next.js and the Install button on the home page links to:

  vibebud-desktop-setup.exe   (Windows)
  vibebud-desktop.dmg         (macOS)
  vibebud-desktop.AppImage    (Linux)
  vibebud.apk                 (Android)

Until real installers are produced, the Install button downloads this README
as a placeholder so the flow is clickable end-to-end.
